# apnamerit.com live review — 1 November 2026

Reviewed against `apnamerit-MASTER-PLAN.md`. Checked with curl/PowerShell (HTML, headers, sitemap, robots, llms.txt, data JSON) and the built-in browser (calculator and predictor on desktop and 375px mobile). PageSpeed Insights API was rate-limited (429), so Core Web Vitals were not scored; run https://pagespeed.web.dev/ by hand.

## Verdict

The build follows the plan closely and the foundation is better than every competitor page we studied: one URL per keyword, answer block on top, official source on every row, FAQPage + Dataset + WebApplication schema from the theme, public CC BY data, llms.txt, AI bots allowed, no fonts, no images, one 20 KB JS file, LiteSpeed + CDN cache hits, clean redirects (http, www, no-slash all 301), custom 404.

What is missing is coverage, not quality. The site has 14 calculators but only 4 merit lists, and the single biggest engineering keyword pair (UET Lahore) has no page at all.

## P0 — fix before anything else

1. **UET Lahore is missing entirely.** `/uet-aggregate-calculator/` and `/uet-merit-list/` return 404. Keyword Planner: "uet aggregate calculator" 5,000/mo, "uet merit list" 5,000/mo, same size as NUST. UET Taxila and UET Peshawar exist, but a student typing "uet" means UET Lahore. Build both pages from `https://apply.uet.edu.pk/pdf/MinimumAggregate2-1.pdf` (per-campus LHR/KSK/FSD, categories A1/A2) and the galleries at `https://uet.edu.pk/.galleries/admission/`.

2. **Predictor labels the 2024 KEMC figure as 2025.** On `/mdcat-aggregate-calculator/` with 160/180, 1010/1100, 1050/1100 (aggregate 90.72%), the "Where can you get in?" block says "MBBS (public) King Edward Medical University closed at 96.06% (2025), you are -5.34". The merit-list table and `/data/uhs.json` say 96.06% is the 17th (last) list of **2024**; the 2025 final list is 94.87%. The same shift appears on AIMC (95.60 shown vs 94.50/2025 in the table), SIMS, NMC, RMC and the other public colleges. Likely cause: the predictor takes the highest value across the two years (or the first record) and prints the newest year label. Fix the selection to "newest year, latest list of that year" and add a unit test that compares every predictor row against the table for the same program. Private colleges look correct, so check whether the bug is tied to lists named "17th (last)" vs "Final".

3. **10 of 14 calculators have zero merit records**, so their "Where can you get in?" block never appears (air, bahria, comsats, fast, giki, iiui, itu, ned, nust, uaf, uet-peshawar all show `records: 0` in `/data/index.json`). The plan's whole differentiator is calculator → "where can I get in" on the same page. Priority order by search volume: UET Lahore (new), NUST (closing merit positions from the official "Closing Merit Positions" page, stored as rank with a note), COMSATS, FAST, then the rest. Until a university has data, show a short "closing merit for X is coming, see the Y merit list" line rather than nothing.

## P1 — do in the next phase

4. **Merit-list pages exist only for UHS, PU, KU, UET Taxila.** `/nust-merit-list/`, `/comsats-merit-list/`, `/fast-merit-list/`, `/uhs-merit-list/` are 404. "nust merit list" alone is 5,000/mo. Each new dataset in P0-3 should ship with its `/<uni>-merit-list/` page.

5. **Mobile table hides the number that matters.** At 375px the MDCAT merit table shows Program, Campus, List, Year and cuts off the closing-aggregate column (needs a horizontal scroll inside the table). Move "Closing %" to the second column, or make the first column and the closing column sticky, so a phone user sees program + percentage without scrolling sideways. No page-level horizontal overflow (scrollWidth 375 = innerWidth), so only the table needs the change.

6. **TTFB from Pakistan is uneven.** Five curl runs on cached pages: 0.63s, 0.82s, 0.85s, 1.17s, 2.77s (home). `x-litespeed-cache: hit` and `x-hcdn-cache-status: HIT` were both present, so the slow runs are edge/network, not PHP. Check Hostinger CDN is on for the domain and that the home page is not being purged on every save; re-measure from a PK mobile connection. Target in the plan: TTFB under 0.8s.

7. **Missing `ads.txt`** (404). Fine until AdSense is applied for; add it in the AdSense phase.

8. **`/merit-data-report-2026/` says "at the end of the 2026 season"** while the same site says UHS 2026 lists are not published yet. Either rename it "Merit Data Report (2025 season data)" or add a visible "updated as lists arrive" note so it does not read as finished.
